Bash / bsub

bsub

tipo/sintaxislang/bash

El comando bsub es un componente clave del IBM Spectrum LSF (Load Sharing Facility) es usado para subir/mandar jobs a ejecución en un clúster de alto rendimiento. En el caso de este proyecto el farm22 del Wellcome Sanger Institute.

Uso básico

Para mandar un job usando bsub puedes hacerlo directamente de la terminal o dentro de un script de bash.

Comando rápido

Para subir un comando simple directamente desde la terminal como por ejemplo, ejecutar un script de python usando el comando python de bash, pasas ese comando como un argumento:

bsub -q normal -J "hello_jobs" python hello_world.py

Subirlo mediante un script de bash (recomendado)

Para tareas complejas, donde es mejor tener organizados los diferentes parámetros, la mejor práctica es escribir un job script. Para hacer que bsub suba este script de forma adecuada, redireccionas el script usando < para indicar que, de alguna forma, bsub contiene y manda el job:

bsub < submit_job.sh

Ejemplo de un job script

A continuación hay una plantilla que contiene diferentes parámetros y su significado comentado para hacer un job script.

#!/bin/bash
#BSUB -J data_process          # Asigna un nombre al job
#BSUB -q normal                # Especifica la cola de espera
#BSUB -n 4                     # Pide 4 núcleos al clúster
#BSUB -R "span[ptile=4]"       # Pide que los 4 núcleos estén en el mismo host
#BSUB -M 4GB                   # Es el límite de memoria
#BSUB -W 02:00                 # El tiempo límite para ejecutar el job
#BSUB -o job_output.%J.txt     # Crea un archivo de la salida estándar de la ejecución
#BSUB -e job_error.%J.txt      # Crea un archivo de la salida del error de la ejecución

# --- Como buena práctica debes de iniciar los módulos al principio y definir el directorio de trabajo ---

module load python/3.10
cd /path/to/my/project

python main.py

Comandos útiles después de subirlo

Una vez hayas subido bsub, puedes monitorear el proceso usando diferentes comandos de LSF:

  • bjobs: Puedes ver el estatus del job, si está en ejecución RUN o si sigue en cola PEND. (Si eres un desesperado como yo, esto será muy útil)
  • bpeek: Un vistazo a las líneas de salida stdout/stderr antes de que el job en ejecución termine.
  • bkill <job_id>: MATAS al job, es decir, haces que deje de ejecutarse o lo quitas de la cola.
